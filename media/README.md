# Sley media kit

The Sley wordmark combines outlined lettering with one red thread passing over
the `l` and beneath the `e`.

| Use                    | Vector                                   | Transparent PNG                          |
| ---------------------- | ---------------------------------------- | ---------------------------------------- |
| Light background       | [Primary SVG](sley-wordmark.svg)         | [Primary PNG](sley-wordmark.png)         |
| Dark background        | [Reverse SVG](sley-wordmark-reverse.svg) | [Reverse PNG](sley-wordmark-reverse.png) |
| One-color reproduction | [Monochrome SVG](sley-wordmark-mono.svg) | [Monochrome PNG](sley-wordmark-mono.png) |

Prefer SVG whenever the destination supports it. Preserve the aspect ratio and
leave clear space around the wordmark. Do not rearrange the letters, move the
thread, add effects, or place the primary version on a dark background.

## Colors

- Ink: `#171717`
- Thread: `#d92d20`
- Reverse ink: `#ffffff`

The outlined letterforms derive from Noto Sans Black, distributed under the SIL
Open Font License 1.1. The final SVG files contain paths and require no font.
